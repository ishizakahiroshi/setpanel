## ja

Windows Terminal のペインを1コマンドで均等なグリッドに分割するPowerShellツールです。複数ペイン構成の立ち上げを毎回手で組む手間を、一発で解消します。

## en

A PowerShell tool that splits Windows Terminal into an even grid of panes with one command — no more manually arranging a multi-pane layout every time.
